# Protocolo P3C - Landing Page

Landing page responsiva para o Protocolo P3C (Crescimento de Caixa), desenvolvida com HTML, Tailwind CSS e Vite.

## Tecnologias Utilizadas

- **HTML5/CSS3**
- **Tailwind CSS** (via CDN)
- **Vite** (Build Tool)
- **Solar Icon Set** (via Iconify)
- **Google Fonts** (Playfair Display & Inter)

## Como rodar o projeto

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Rode o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Para gerar a versão de produção:
   ```bash
   npm run build
   ```
